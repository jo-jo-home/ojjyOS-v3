# BROWSER_CHROME_PLAN.md — a Chrome-like browser for ojjyOS (2026-10-19)

Jonas: "i want it to feel like chrome ... add all the features of chrome and
also i cant even go to some certain websites like i need a great browser",
then "make a whole new browser just like chrome and maybe if u can even add
the actual chrome to my os".

## 0. Can real Chrome run on ojjyOS? No (and why)

Chrome/Chromium is ~35 million lines of C++ that expects a full POSIX-style
OS underneath: many processes and threads (renderer sandboxes, GPU process,
network service), `mmap`/shared memory, a dynamic loader, hundreds of
system calls, a C++ runtime, GPU drivers (or SwiftShader) and fonts via
FreeType/fontconfig. ojjyOS runs one protected EL0 program at a time with a
six-call ABI, and Jonas's rule is "no Linux/BSD underneath". Porting it would
first mean writing most of a Linux-compatible kernel and userland. So this
plan builds **a new browser that looks and behaves like Chrome**, written from
scratch for this kernel ("ojjyOS Web"; it must not use Google's name/logo).

## 1. Where the browser stands (measured, `build/web-before`)

`tests/qemu_web_tour.py` (new) visits 18 popular sites on a private disk:
- Networking is fine: 17/18 load (TLS 1.3 + HTTP/1.1). Host probe
  (`tests/tls_probe.c` against 32 sites) agrees. craigslist.org fails the
  handshake (needs TLS 1.2 or a HelloRetryRequest -> Track N).
- The **engine** is the problem: one-pass flow layout, **no CSS at all**
  (Wikipedia renders as a 1993 link list), **no images**, **no JavaScript**
  (reddit.com/youtube.com render blank), typed searches go to Wiby (an
  obscure plain-HTTP engine), GET-only forms, no cookies, `Accept-Encoding:
  identity` only, one page at a time, 24-entry history, no tabs.

## 2. Ownership change (parallel round)

Track N (`NET_WEB_PLAN.md`) owned the browser. From now on **this work owns
`kernel/src/ui/browser.*`, `kernel/src/web/**`, `kernel/src/image/**`
(PNG/inflate/GIF/progressive JPEG, `image.h`) and the HTTP client**, i.e.
Track N's old N5–N8. Track N keeps N2–N4: X.509, certificate + CertificateVerify
checking in `net/tls.c`, the root store, `clock.c` + SNTP, plus TLS 1.2 /
HelloRetryRequest (craigslist). Recorded in `PARALLEL_PLAN.md` §3.

## 3. Phases (each = build both arches 0 warnings, host + ASan suites, live tests, commit, ff main)

### W1 — New engine: DOM + CSS + layout (the big one)
New files: `web/dom.c/h` (tolerant HTML tree builder into an arena: implied
end tags for p/li/td/tr/option/dt/dd, void and raw-text elements, entities,
UTF-8), `web/css.c/h` (tokenizer, rules, selectors, cascade), `web/layout.c`
(box tree -> display list). `html.h`'s `html_layout()` stays as the entry point.
- Selectors: type, `*`, `.class`, `#id`, `[attr]`, `[attr=v]`, `[attr^=/$=/*=/~=]`,
  descendant, `>`, `+`, `~`, `:first-child`, `:last-child`, `:nth-child(n)`,
  `:not(simple)`, `:root`, `:link`; dynamic (`:hover`, `:focus`) never match;
  `::before/::after` ignored. Specificity, `!important`, source order,
  inheritance. `@media` evaluated against the viewport (screen, min/max-width,
  prefers-color-scheme), `@supports` -> accepted, `@import`/`@font-face`/
  `@keyframes` skipped. CSS custom properties (`--x` + `var()`), because
  most modern sites (Wikipedia included) colour everything through them.
- Properties: display (none/block/inline/inline-block/list-item/flex/
  inline-flex/grid as block/table family), visibility, color, background(-color),
  font-size (px/em/rem/%/keywords), font-weight, font-style, font-family
  (monospace detection), text-align, text-decoration, text-transform,
  line-height, white-space, margin, padding, border(-*), border-radius, width,
  min/max-width, height/min-height (px), box-sizing, list-style-type,
  flex-direction/wrap, justify-content, align-items, gap, position
  (fixed/sticky drawn in flow; absolute off-screen tricks hidden), float
  (approximated), overflow:hidden clipping, opacity 0 hidden.
- Layout: block flow with margins, inline formatting with styled runs and
  line boxes, inline-block, flex rows/columns with wrap and gaps, simple tables
  (auto column widths), list markers, replaced elements (img/input/button/
  select/textarea), `<center>`, `<font color>`, `bgcolor` and other legacy
  attributes, `<details>` open state.
- Display list: background/border rects (rounded), text runs with colour,
  size, weight, decoration; image boxes; link and form-control regions.
- Fonts: web faces generated by `tools/mkuifont.py` (Inter Regular + Bold at
  12/14/16/18/20/24/32 px, 1x and 2x) so CSS sizes render crisply.
- UA stylesheet in CSS (like Chrome's html.css).
- External stylesheets: `<link rel=stylesheet>` fetched after the page
  (bounded count/size), page re-laid when they arrive.
- Host tests: tree builder, selector matching/specificity, cascade/var(),
  layout positions; fuzz (truncation + random corruption) under ASan/UBSan.

### W2 — Chrome shell
- Tab strip in the window's title row (next to the traffic lights): tabs with
  favicon letter-badge/spinner, title, close button; `+` new tab; drag empty
  strip to move the window. Up to 12 tabs (per-tab URL, history, scroll,
  page buffer; one shared layout re-laid on switch).
- Toolbar: back, forward, reload/stop, omnibox (lock / "Not secure" chip, full
  URL when focused, select-all, caret editing), bookmark star, ⋮ menu.
- Omnibox suggestions dropdown: "Search Google for …", history and bookmark
  matches, inline autocomplete; default search Google (`gbv=1` basic HTML),
  DuckDuckGo HTML and Bing selectable in settings.
- Bookmarks bar under the toolbar; Cmd+D to bookmark; `ojjy:bookmarks`.
- New Tab page: search box + most-visited/shortcut tiles.
- History (`ojjy:history`, Cmd+Y), downloads (`ojjy:downloads`), settings
  (`ojjy:settings`: search engine, home page, show bookmarks bar, clear
  browsing data), all persisted in `~/Library/Web/`.
- Find in page (Cmd+F bar, highlights, n/m count, Enter/Shift+Enter),
  zoom (Cmd +/-/0, per-site), view source (Cmd+U / `view-source:`),
  right-click menu (open link in new tab, copy link, back, forward, reload,
  view source), Cmd-click / middle-click = new background tab, hover URL
  bubble bottom-left, Cmd+T/W/Shift+T (reopen closed), Cmd+1..9,
  Ctrl+Tab/Ctrl+Shift+Tab, Cmd+L, Cmd+R, Cmd+[ ], Esc stops.
- Larger default window; Chrome-like light/dark chrome in the blue Tahoe theme.

### W3 — Images, compression
`image/inflate.c` (DEFLATE, zlib, gzip), `image/png.c` (all colour types,
interlace, palette, tRNS), `image/gif.c` (first frame), progressive JPEG in
`jpeg.c` (baseline must stay byte-identical for the wallpapers), `image.h`
dispatch per PARALLEL_PLAN. `<img>`/`<picture>`/`srcset` (pick a fitting
candidate), CSS width/height and aspect ratio, lazy `data-src` fallbacks,
bounded image cache, background fetch queue (several connections), smooth
scaled blit. `Accept-Encoding: gzip` for pages (+ host tests/fuzz).
WebP/SVG/AVIF: placeholders with alt text (later).

### W4 — Network compatibility
Cookie jar (Set-Cookie: Domain/Path/Secure/HttpOnly/Max-Age/Expires/SameSite,
per-user persisted, cleared from settings), POST forms
(application/x-www-form-urlencoded), redirect limit 10 incl. POST->GET,
Referer, bigger page buffer, more TLS slots, `<meta http-equiv=refresh>`,
charset (UTF-8/Latin-1/Windows-1252), better error pages (Chrome-style
"This site can't be reached" with the reason).

### W5 — JavaScript honesty
No JS engine this round (a real one is its own multi-week project). Pages
that are empty without JS get a Chrome-style info bar: "This page needs
JavaScript, which ojjyOS Web doesn't run yet", with known lighter versions
offered (old.reddit.com, lite.cnn.com, html.duckduckgo.com, m.youtube? no).
`<noscript>` content is shown.

### W6 — Finish
Docs (APPS.md Web section, README, this log), the in-OS What's New page,
installed images rebuilt when no VM runs, plain-English summary.
