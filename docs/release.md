# ojjyOS release checklist

The step-by-step runbook for cutting an ojjyOS release (roadmap card
QA-40). Work through it top to bottom; every command is meant to be
copy-pasteable from a checkout of the release commit. The in-OS pages
are generated by `scripts/mkfs.sh` — edit there, never the files under
`sysroot/` directly. Created by Jonas Lee.

## 0. Freeze and branch state

- [ ] All cards for the release are `Status: done`; `python3
      roadmap/tools/roadmap.py check` prints no errors and
      `roadmap.py status` shows nothing unexpected in `doing`.
- [ ] `main` holds everything (fast-forward only); every worktree is
      clean (`git status --porcelain` empty after a full build —
      card QA-22).
- [ ] The full test day ran green on this commit (QA matrix:
      dev builds, host + ASan/UBSan, smoke TCG/HVF/Intel, tours,
      VZ boot/smoke) — evidence under `build/qa-YYYY-MM-DD/`.

## 1. Version bump (four places, in ONE commit)

Pick `X.Y.Z`; update all four in the same commit so nothing drifts:

- [ ] `OJJYOS_VERSION` in `kernel/src/main.c` (boot splash + serial
      banner strings around it).
- [ ] About window: `draw_about_window` in
      `kernel/src/ui/compositor.c`.
- [ ] `sysroot/System/version.txt` — the heredoc in `scripts/mkfs.sh`.
- [ ] Boot art version line in `kernel/src/main.c` if the release
      string appears there.

## 2. Changelog / What's New

- [ ] Update the release page heredoc (`release.html`) in
      `scripts/mkfs.sh`: move the old "Also new" items into "Earlier"
      and write the user-facing list for this release.
- [ ] Update `RELEASE.md`'s title/header version.
- [ ] `THIRD_PARTY.md` is current (`tools/check_third_party.py` runs
      in `scripts/test.sh`; QA-40 re-checks it here).

## 3. Full verification matrix on the release commit

- [ ] `bash scripts/test.sh` and
      `HOST_CC=/opt/homebrew/opt/llvm/bin/clang OJJY_SANITIZE=1 bash scripts/test.sh`.
- [ ] `OJJY_BUILD_DIR="$PWD/build/dev-aarch64" ARCH=aarch64 bash scripts/build.sh`
      and the same for `x86_64` — zero warnings both.
- [ ] `bash scripts/build-vmapp.sh` and `bash scripts/test-vmapp.sh`
      (Swift guards plus Python pixel gates; Python needs Pillow).
- [ ] Smoke: `OJJY_ACCEL=tcg python3 -B tests/qemu_smoke.py --arch aarch64 --image build/dev-aarch64/ojjyos3.img --output build/rel-smoke-tcg --fresh-data --protected`,
      repeat with `OJJY_ACCEL=hvf`, and once with `--arch x86_64`
      against `build/dev-x86_64/ojjyos3.img`. Use the freshly built images,
      not a previously installed image from another revision.
- [ ] `python3 -B tests/vz_launch.py --image build/dev-aarch64/ojjyos3.img --output build/rel-launch`
      (private launch/settings, screens, network, fullscreen and pointer matrix).
- [ ] Tours under HVF (design, apps, apps-check, web) — screenshots
      reviewed with `tools/qa_shots.py` at minimum.
- [ ] Security review pass per card SEC-02 (creds, VFS isolation,
      parsers; re-run its host tests; note any accepted gaps).
- [ ] Design gallery diff per card DS-15 (light + dark captures of
      the shipped surfaces, compared to the previous release).

## 4. Delivery (no VM may be running — check `pgrep -fl 'ojjyOS.app/Contents|qemu-system'`)

- [ ] Fast-forward the main checkout `ojjyOS-v3` to the release
      commit, then `ARCH=aarch64 bash scripts/build.sh` and
      `ARCH=x86_64 bash scripts/build.sh` from it (the data-preserving
      builder). Verify the data partitions: user-data SHA-256 before
      and after must match, backups retained.
- [ ] `bash scripts/build-vmapp.sh` (the native app ships the launch
      menu settings; `build/launch-settings.json` is preserved).
- [ ] VZ boot check on a private copy of the delivered image
      (`tests/vz_boot.py`) plus `tests/vz_smoke.py`.
- [ ] `python3 ~/.claude/skills/ojjyos/scripts/ready_to_test.py
      --repo ~/Developer/ojjyOS-kernel/ojjyOS-v3 --by <tool>
      --summary "Release X.Y.Z" --try ... --known ... --tests ...`.

## 5. Tag and summary

- [ ] `git tag vX.Y.Z` (local; the repo pushes only when Jonas says
      so).
- [ ] Write Jonas the release summary: headline features, known issues
      (from `bugs/OPEN.md`), how to try it, evidence directories.
- [ ] Update AGENTS.md LATEST with the release state.

## 3.2 runbook
