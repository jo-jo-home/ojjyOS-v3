# Third-party assets in ojjyOS

ojjyOS is an original operating system: its kernel, desktop, apps and
browser are written from scratch (see `LICENSE` for the project licence).
This register lists every third-party asset, data set or program that the
repository and the OS image contain or will contain, with its licence and
source, per roadmap card DOC-03 and decision D-023 (third-party programs
only ever ship as optional ojjypkg packages, never inside the base image).

A copy of this file ships inside the OS image as
`/System/Legal/THIRD_PARTY.txt` (About > legal information).

Created by Jonas Lee. Last updated: 2026-10-27.

---

## fonts/ — typefaces (shipped, SIL Open Font License 1.1)

| Asset | Files | Licence | Source |
|---|---|---|---|
| Inter (Regular, Medium, SemiBold, Bold) | `fonts/Inter-*.ttf`, `fonts/Inter-OFL-LICENSE.txt` | SIL OFL 1.1 | https://github.com/rsms/inter — Rasmus Andersson and the Inter project |
| JetBrains Mono (Regular) | `fonts/JetBrainsMono-Regular.ttf`, `fonts/OFL-LICENSE.txt` | SIL OFL 1.1 | https://www.jetbrains.com/lp/mono/ — JetBrains s.r.o. |

The OFL permits bundling, modifying and subsetting. Both licences are
kept next to the font files, and the text rendered into the image by
`scripts/mkfs.sh` below notes them again.

### Generated font data (shipped, derived from the fonts above)

- `kernel/src/uifont_data.c` — Inter glyph bitmaps generated by
  `tools/mkuifont.py` from `fonts/Inter-*.ttf` (subset + SDF-style
  bitmap rendering). A derivative of Inter under the same OFL 1.1.
- `kernel/src/uifont_data.c` browser text and `kernel/src/webfont_data.c`
  — Inter subsets for the browser, generated the same way (OFL 1.1).
- `kernel/src/font.c`, `kernel/src/font2x.c` — JetBrains Mono console
  bitmaps generated by `tools/mkfont.py` / `mkfont2x.py` from
  `fonts/JetBrainsMono-Regular.ttf` (OFL 1.1).

## Wallpapers — Apple macOS Tahoe pictures (NOT shipped, never committed)

The 17 Tahoe desktop pictures Jonas uses personally live only in the
git-ignored folder `wallpapers/local/` (fetched once by
`tools/import_wallpapers.py --fetch`). They are Apple's copyrighted
artwork: they are never committed to the repository, never pushed, and
never written into the OS image or any release artifact
(`scripts/mkimg.sh` packs them only into Jonas's own local disk image
data area at LBA 102400). A fresh clone builds and boots with the
procedural wallpapers only. This policy covers any future Apple asset.

## sysroot/ and programs/ — original content (shipped)

Everything the OS image itself contains — apps, icons
(`tools/mkicons.py`), wallpapers (procedural waves), Web pages, sample
documents and the protected ARM64 sample programs in `sysroot/System/Programs`
— is original work by Jonas Lee, generated from original code in
`tools/` and `programs/`. No third-party bytes are packed into the base
image.

## packages/ — optional ojjypkg programs (not shipped yet)

Decision D-023: third-party open-source programs and libraries may be
ported later, but only as optional `ojjypkg` packages installed by the
user — never as part of the base image. No packages exist yet. When the
first one lands (see roadmap phase 6/7, area PKG), add one row per
package here: name, version, upstream URL, licence and licence text
file, plus which ojjypkg manifest ships it.

## CA root certificates — TLS trust anchors (shipped, public data)

`kernel/src/crypto/roots_data.c` holds 51 public web root CAs (Let's
Encrypt/ISRG, DigiCert, GlobalSign, Google Trust Services, Amazon,
Starfield/GoDaddy, Sectigo/USERTrust/Comodo, Microsoft, SSL.com, Certum,
Actalis, HARICA, Buypass, IdenTrust, Certainly). Only each root's subject
name and public key are stored — the facts certificate verification needs
— generated by `tools/mkroots.py` from the macOS system root store (the
same roots are published by each CA and in Mozilla's CCADB-derived list).
Each entry's comment carries the root's SHA-256 fingerprint and expiry;
regenerate with `python3 -I tools/mkroots.py > kernel/src/crypto/roots_data.c`
(or `--pem <bundle>` on Linux). Root certificates are public data meant for
redistribution; no licence text is required.

`tests/x509_real.h` holds real certificate chains of six public web sites
(captured by `tests/gen_x509_real.py`, also public, logged in Certificate
Transparency) for the host tests only; it is not part of the image.

## Future data sets (not shipped yet)

Each of these will be third-party data with a permissive licence; none
is in the repository or the image yet. When one lands, record source,
version/snapshot date and licence here and keep the licence text inside
the image.

- **Time zone database** (area SET): the public-domain IANA
  `tzdata` for the Clock/Calendar time zone picker.
- **Dictionaries** (area APP): spell-check word lists, e.g. SCOWL
  (Apache 2.0 / permissive) for English.
- **Unicode data** (area I18N): Unicode CLDR / character-name tables
  (Unicode License v3) for text rendering and the character viewer.
- **Sample media** (area APP-MUSIC/APP-VIDEO): only freely licensed
  (CC0/CC-BY) fixtures for the media players.

## Verification

`tools/check_third_party.py` checks that this register keeps its
required sections (fonts, packages, wallpapers policy) and runs from
`scripts/test.sh`; roadmap card QA-40 (release checklist) re-checks it
for every release.
