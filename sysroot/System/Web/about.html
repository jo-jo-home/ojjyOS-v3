About ojjyOS

ojjyOS is a custom operating system with a macOS Tahoe-inspired user interface. It is built from scratch on a custom kernel — not based on Linux, BSD, Windows or macOS.

Created by Jonas Lee.

Inside

  • Custom kernel for ARM64 (Apple Silicon VMs) and x86-64
  • Its own network stack: Ethernet, ARP, IPv4, DHCP, DNS, TCP, HTTP and TLS 1.3
  • This browser: HTML layout engine, links, forms and history
  • Finder, Terminal, TextEdit, Notes, Preview, Calendar, Calculator, Settings and more
