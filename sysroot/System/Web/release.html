ojjyOS 3.1

New: ojjyOS Web

  • A new browser engine — real CSS (selectors, cascade layers, variables, flexbox, grid, floats, positioning, media queries), so sites look like their real selves.
  • Pictures — PNG, JPEG (incl. progressive), GIF, WebP and SVG logos and icons.
  • Tabs, bookmarks and history — a Chrome-style tab strip, smart address bar with suggestions, bookmarks bar, history, downloads, find in page, zoom and view source.
  • Faster pages — gzip-compressed downloads (often 6x less data) and cookies.
  • Searches go to DuckDuckGo; pages that need JavaScript say so and offer lighter versions.

Also new

  • Networking — a from-scratch network stack with DHCP, DNS and TCP.
  • A real web browser — open websites, follow links, search and fill in forms.
  • HTTPS — TLS 1.3 written from scratch (x25519, ChaCha20-Poly1305, AES-GCM).
  • Terminal network tools — ifconfig, ping, nslookup, curl.
  • Accurate, fast mouse pointer and a cleaner blue desktop.

Earlier

  • Protected ARM64 apps (run hello in Terminal)
  • Reliable boot, input and saved storage
  • Dock, Spotlight, Launchpad, Control Center and Mission Control
