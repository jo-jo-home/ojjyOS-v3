ojjyOS 3.1

New: ojjyOS Web

  • A new browser engine — real CSS (selectors, cascade layers, variables, flexbox, grid, floats, positioning, media queries), so sites look like their real selves.
  • Pictures — PNG, JPEG (incl. progressive), GIF, WebP and SVG logos and icons.
  • Tabs, bookmarks and history — a Chrome-style tab strip, smart address bar with suggestions, bookmarks bar, history, downloads, find in page, zoom and view source.
  • Faster pages — gzip-compressed downloads (often 6x less data) and cookies.
  • Searches go to DuckDuckGo; pages that need JavaScript say so and offer lighter versions.

Also new

  • More memory, for real — ARM64 and Intel now manage RAM above 4 GiB. About shows measured RAM; Activity Monitor separates managed, used, free and reserved memory. Protected ARM64 programs and selected browser/TLS buffers can use high RAM; device/DMA buffers remain below 4 GiB. The launch menu's temporary 2.2 GB warning is gone.
  • HTTPS you can trust — every https:// site must now prove who it is: ojjyOS checks its certificate chain against 51 built-in root authorities, the name and the dates, and the server's signature. A lock means the check passed; a bad certificate shows "This connection is not private" with the reason, Go Back and a small "Visit anyway". Terminal curl refuses bad certificates unless you add -k.
  • Calendar, Calculator, Activity Monitor and About — glass Calendar header and today circle, Calculator equation history and key feedback, Monitor tabs with memory bars and measured renderer frame times, and a clearer version card with Jonas Lee's credit.
  • Accurate clock — the system now syncs to NTP time servers after connecting, so the menu bar clock is always right; Terminal date shows the corrected time and ntp forces a sync.
  • TextEdit — long paragraphs now soft-wrap at word boundaries, the status bar shows word and character counts, and saving pops a notification. Home/End and Page Up/Down work, and Backspace mid-line no longer eats the rest of the line.
  • Notes — a sidebar with all your notes, New Note, and saving by itself while you type.
  • Networking — a from-scratch network stack with DHCP, DNS and TCP.
  • A real web browser — open websites, follow links, search and fill in forms.
  • HTTPS — TLS 1.3 written from scratch (x25519, ChaCha20-Poly1305, AES-GCM).
  • Terminal network tools — ifconfig, ping, nslookup, curl.
  • Accurate, fast mouse pointer and a cleaner blue desktop.

Earlier

  • Protected ARM64 apps (run hello in Terminal)
  • Reliable boot, input and saved storage
  • Dock, Spotlight, Launchpad, Control Center and Mission Control
