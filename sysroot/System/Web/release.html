ojjyOS 3.1

New

  • Networking — a from-scratch network stack with DHCP, DNS and TCP.
  • A real web browser — open http:// websites, follow links, search and fill in forms.
  • Terminal network tools — ifconfig, ping, nslookup, curl.
  • Accurate, fast mouse pointer and a cleaner blue desktop.

Earlier

  • Protected ARM64 apps (run hello in Terminal)
  • Reliable boot, input and saved storage
  • Dock, Spotlight, Launchpad, Control Center and Mission Control
